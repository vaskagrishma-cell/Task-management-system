
# Task Management System

A simple Task Management Application developed using Python, Flask, and MySQL.

## Features
- User Registration
- User Login and Logout
- Add New Tasks
- Edit Existing Tasks
- Delete Tasks
- Update Task Status
- View All Tasks

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Configure MySQL credentials in the `.env` file.

3. Create the database and tables.

4. Run the application:

   py app.py

5. Open http://127.0.0.1:5000 in your browser.
